Домашнє завдання

Мета: за допомогою ШІ створити HTML-сторінку про себе, не вказуючи ім’я, перевірити інформацію та підготувати файл до здачі.

1. Підготовка (5 хв)
- Створити на комп’ютері папку для домашнього завдання.
- Відкрити звичайний текстовий редактор (Блокнот, TextEdit у режимі простого тексту).
- Натиснути "Файл → Зберегти як".
- У полі "Ім’я файлу" ввести `index.html`.
- У полі "Тип файлу" вибрати "Усі файли".
- Зберегти файл `index.html` у цій папці.

2. Генерація коду за допомогою ШІ (10 хв)
- Відкрити доступний чат із ШІ.
- Попросити ШІ створити вебсторінку про вас, але не вказувати ваше ім’я.
- У запиті зазначити, що сторінка має містити:
  - три цікаві факти про вас;
  - ваші улюблені речі;
  - ваші хобі та захоплення.
- Попросити оформити сторінку так, щоб вона передавала ваш характер.
- Скопіювати HTML-код у файл `index.html` і зберегти його.

3. Перевірка інформації (10 хв)
- Відкрити `index.html` у браузері.
- Переконатися, що на сторінці немає вашого імені.
- Перевірити, чи всі факти відповідають дійсності.
- Якщо ШІ вигадав або неправильно описав факти, дати йому уточнювальні інструкції.
- Скопіювати виправлений HTML-код у файл `index.html`, зберегти його та оновити сторінку в браузері.

4. Самоперевірка і здача (5 хв)
- Перед здачею перевірити себе:
  - [ ] сторінка відкривається у браузері;
  - [ ] на сторінці не вказано ім’я;
  - [ ] додано три цікаві факти про себе;
  - [ ] зазначено улюблені речі;
  - [ ] описано хобі та захоплення;
  - [ ] усі факти перевірені й відповідають дійсності;
  - [ ] оформлення сторінки передає ваш характер;
  - [ ] файл називається `index.html`.
- Здати згенерований файл `index.html` з інформацією про себе.


На наступному уроці клас спробує вгадати автора сторінки.
