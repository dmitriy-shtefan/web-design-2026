Завдання для самостійної роботи

Мета: за допомогою ШІ створити просту HTML-сторінку на тему "Штучний інтелект навколо нас", перевірити код і здати готовий результат.

1. Підготовка (5 хв)
- Створити на комп’ютері папку `AI_Прізвище`.
- Відкрити звичайний текстовий редактор (Блокнот, TextEdit у режимі простого тексту).
- Натиснути "Файл → Зберегти як".
- У полі "Ім’я файлу" ввести `index.html`.
- У полі "Тип файлу" вибрати "Усі файли".
- Зберегти файл `index.html` у цій папці.

2. Генерація коду за допомогою ШІ (10 хв)
- Відкрити доступний чат із ШІ.
- Скопіювати й надіслати промпт:

  `Створи просту HTML-сторінку українською мовою на тему "Штучний інтелект навколо нас". Додай заголовок, короткий вступ, список із трьох прикладів використання ШІ та висновок. Використовуй лише HTML, без CSS і JavaScript. Додай doctype, html, head, meta charset, title і body. Після коду коротко поясни призначення кожної частини.`

- Скопіювати лише HTML-код у файл `index.html` і зберегти його.

3. Перевірка сторінки (10 хв)
- Відкрити `index.html` у браузері.
- Переконатися, що видно заголовок, вступ, три приклади та висновок.
- Якщо замість сторінки видно код або файл не відкривається, перевірити:
  - чи файл має назву саме `index.html`, а не `index.html.txt`;
  - чи весь код скопійовано від `<!DOCTYPE html>` до `</html>`;
  - чи файл збережено після останніх змін.

4. Аналіз відповіді ШІ (*додаткове завдання з зірочкою).
- У кінці сторінки самостійно додати заголовок "Як відповідально користуватися ШІ".
- Під ним додати короткі відповіді на три питання:
  1. Звідки ШІ міг узяти цю інформацію?
  2. Де у створеній відповіді ШІ може помилятися?
  3. Хто відповідає за перевірку готового результату?
- Зберегти файл і оновити сторінку в браузері.

5. Самоперевірка і здача (5 хв)
- Перед здачею перевірити себе:
  - [ ] сторінка відкривається у браузері;
  - [ ] текст написаний українською мовою;
  - [ ] є заголовок, вступ, три приклади та висновок;
  - [ ] є власні відповіді на три питання про ШІ (*якщо виконано);
  - [ ] файл називається `index.html`.
- Зробити скріншот відкритої сторінки.
- Надіслати файл `index.html` і скріншот у Teams чат уроку або вчителю.
