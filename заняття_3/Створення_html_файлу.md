Найпростіше — використати стандартний **Блокнот** у Windows.

1. Відкрийте Блокнот.
2. Вставте HTML-код, наприклад:

```html
<!DOCTYPE html>
<html lang="uk">
<head>
    <meta charset="UTF-8">
    <title>Моя перша сторінка</title>
</head>
<body>
    <h1>Привіт, світе!</h1>
    <p>Це моя перша вебсторінка.</p>
</body>
</html>
```

3. Натисніть **Файл → Зберегти як**.
4. У полі «Ім’я файлу» введіть `index.html`.
5. У полі «Тип файлу» виберіть **Усі файли**.
6. Кодування залиште **UTF-8**.
7. Збережіть файл в папці з Документами або на Робочому столі.
8. Двічі клацніть `index.html` — сторінка відкриється у браузері.

Важливо: файл має називатися саме `index.html`, а не `index.html.txt`.

Для редагування учням достатньо натиснути на файл правою кнопкою миші → **Відкрити за допомогою → Блокнот**, 
змінити код, зберегти його через `Ctrl + S`, а потім оновити сторінку в браузері клавішею `F5`.
