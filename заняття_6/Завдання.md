# Завдання

Сьогодні у нас завдання створити персональну стрічку для Олі або Данила.

1. Оберіть для кого буде ваша стрічка: для Олі або Данила. 
2. Відкрийте зображення з історією переглядів.
3. Оберіть із переліку нижче шість нових матеріалів.
4. Розмістіть їх від найімовірнішої рекомендації до менш імовірної.
5. Оформіть стрічку як маркований HTML-список `<ul>` із шістьма пунктами `<li>`.
6. Для перших трьох пунктів після тире напишіть коротку причину вибору.

Використовуйте лише вигадані історії Олі та Данила. 

## 12 варіантів нового контенту

### Відеоігри

1. **Як пройти складний рівень** — практичні поради для проходження гри.
2. **Створюємо цифрового персонажа для гри** — покроковий творчий урок.
3. **Як музика змінює атмосферу відеогри** — пояснення з прикладами саундтреків.

### Самокати

4. **Три базові трюки на самокаті в захисному спорядженні** — навчальне відео для початківців.
5. **Як вибрати шолом і захист для катання на самокаті** — правила безпечного катання.
6. **Подорож містом на самокаті: плануємо безпечний маршрут** — поєднання катання та орієнтування в місті.

### Музика

7. **Плейлист для навчання** — спокійна музична добірка.
8. **Як створюють ритм електронної композиції** — короткий розбір музичного треку.
9. **Вчимо простий ритм на гітарі** — практичний урок для початківців.

### Подорожі

10. **Вихідні у Львові: маршрут історичним центром** — добірка місць для прогулянки.
11. **Як спланувати подорож потягом** — квитки, маршрут і необхідні речі.
12. **Віртуальна подорож замками України** — пізнавальна онлайн-екскурсія.

## Мінімальна структура стрічки

```html
<h1>Стрічка для ...</h1>

<ul>
  <li><strong>Перша рекомендація</strong> — причина вибору.</li>
  <li><strong>Друга рекомендація</strong> — причина вибору.</li>
  <li><strong>Третя рекомендація</strong> — причина вибору.</li>
  <li>Четверта рекомендація</li>
  <li>П'ята рекомендація</li>
  <li>Шоста рекомендація</li>
</ul>
```
