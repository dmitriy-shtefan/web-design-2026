# Домашнє завдання: HTML-сторінка про ваш практичний проєкт

Ви вже попрацювали над власною моделлю в Teachable Machine. Тепер представте свій практичний проєкт на вебсторінці, згенерованій за допомогою ШІ.

Що зробити:
1. Підготуйте короткий опис свого проєкту: тему, назви класів, для чого потрібна модель, які фото ви використали для навчання та який результат отримали під час перевірки.
2. Складіть запит до ШІ та попросіть згенерувати одну HTML-сторінку про ваш проєкт. Укажіть зміст, бажані кольори й оформлення. Попросіть розмістити CSS усередині HTML, щоб сторінка працювала як один файл без додаткових завантажень.
3. Збережіть отриманий код у файлі `index.html` і відкрийте його у браузері. Переконайтеся, що файл має розширення `.html`.
4. Перевірте текст і вигляд сторінки. Якщо помітили неточність або незручне оформлення, попросіть ШІ виправити її та збережіть оновлений код.

Що має бути на сторінці:
- Назва вашого проєкту та короткий опис.
- Список класів, які розрізняє модель.
- Опис навчальних фото: скільки їх і чим вони відрізняються.
- Один фактичний приклад перевірки: що було на новому фото, яку відповідь ви очікували та що відповіла модель.
- Короткий висновок: де модель може помилитися та чому людині потрібно перевіряти її відповідь.

Використовуйте дані зі своєї картки проєкту.

Що здати:
- Файл `index.html` вашої сторінки.


## Приклад запиту до ШІ

```text
Створи HTML-сторінку українською мовою про мій практичний проєкт у Teachable Machine.

Ось факти про мою роботу:
[Вставте тему, короткий опис проєкту, класи, опис навчальних фото, результат перевірки та обмеження моделі.]

Додай заголовок, короткий вступ, список класів, розділ про навчальні дані, результат перевірки та висновок.

Оформлення: [світлий фон, читабельний текст, зелені акценти]. Сторінка має зручно відображатися на комп'ютері й телефоні.

Надай повний код одного файлу index.html. Розмісти CSS усередині HTML. Сторінка має відкриватися локально без додаткових файлів і бібліотек.
```

Замініть текст у квадратних дужках своїми даними. Оберіть власні кольори та стиль.
