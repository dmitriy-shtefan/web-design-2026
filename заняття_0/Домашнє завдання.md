# Домашнє завдання: «Моя галактика»

Ви вже вмієте створювати заголовки, текст і списки в HTML. У цьому завданні потрібно поєднати ці елементи на одній фантастичній сторінці та додати до неї просте оформлення.

## Що потрібно створити

Створіть вебсторінку про вигадану галактику. Придумайте для неї назву, короткий опис і п'ять планет. Для кількох планет додайте списки з їхніми особливостями.

Наприклад, ваша галактика може називатися **Аурелія**, а її планети — **Люміна**, **Флора**, **Акварія**, **Кристалія** та **Нова**. Це лише приклад: придумайте власні назви та описи.

## Що має бути на готовій сторінці

1. Назва галактики у заголовку `<h1>`.
2. Короткий опис галактики у тегу `<p>` — 2–3 речення.
3. Нумерований список `<ol>` із п'яти планет.
4. Для 2–3 планет — вкладений маркований список `<ul>` з їхніми особливостями.
5. Щонайменше одне ключове слово, виділене тегом `<strong>`.
6. Оформлення сторінки за допомогою CSS: колір тла, колір заголовка та читабельний колір тексту.

## Виконуйте завдання поетапно

### Крок 1. Підготуйте файли

Створіть в одній папці два файли:

- `index.html` — у ньому буде зміст сторінки;
- `style.css` — у ньому буде оформлення сторінки.

Підключіть файл зі стилями всередині тегу `<head>`:

```html
<link rel="stylesheet" href="style.css">
```

Якщо ви працюєте в онлайн-редакторі, HTML-код пишіть у полі **HTML**, а стилі — у полі **CSS**.

### Крок 2. Створіть основу HTML-сторінки

Скопіюйте цей шаблон у файл `index.html`:

```html
<!DOCTYPE html>
<html lang="uk">
<head>
    <meta charset="UTF-8">
    <title>Моя галактика</title>
    <link rel="stylesheet" href="style.css">
</head>
<body>
    <!-- Тут буде вміст сторінки -->
</body>
</html>
```

Увесь видимий вміст сторінки додавайте між тегами `<body>` і `</body>`.

### Крок 3. Додайте назву та опис галактики

Замість тексту з прикладу напишіть власну назву й опис:

```html
<h1>Галактика Аурелія</h1>

<p>
    Аурелія сяє золотим світлом і має п'ять незвичайних планет.
    Її головна особливість — <strong>різнокольорові зорі</strong>.
</p>
```

Тег `<strong>` виділяє важливі слова жирним шрифтом.

### Крок 4. Додайте п'ять планет

Для нумерованого списку використайте `<ol>`. Кожну планету запишіть в окремому елементі `<li>`:

```html
<h2>Планети галактики</h2>

<ol>
    <li>Перша планета</li>
    <li>Друга планета</li>
    <li>Третя планета</li>
    <li>Четверта планета</li>
    <li>П'ята планета</li>
</ol>
```

Замініть слова «Перша планета», «Друга планета» тощо на власні назви.

### Крок 5. Опишіть особливості 2–3 планет

Маркований список `<ul>` потрібно розмістити **всередині** елемента `<li>` відповідної планети. Наприклад:

```html
<ol>
    <li>
        Люміна
        <ul>
            <li>Атмосфера: тепла та прозора</li>
            <li>Рослинність: дерева, що світяться</li>
            <li>Життя: мешкають маленькі крилаті істоти</li>
        </ul>
    </li>

    <li>
        Флора
        <ul>
            <li>Атмосфера: волога</li>
            <li>Рослинність: планету вкривають великі квіти</li>
            <li>Життя: розумні тварини</li>
        </ul>
    </li>

    <li>Акварія</li>
    <li>Кристалія</li>
    <li>Нова</li>
</ol>
```

Не копіюйте опис дослівно — вигадайте особливості власних планет. Можна описати атмосферу, погоду, рослини, тварин, мешканців, океани або інші цікаві явища.

### Крок 6. Оформіть сторінку

Додайте у файл `style.css` прості стилі. Кольори можете замінити на власні:

```css
body {
    background-color: #101537;
    color: #ffffff;
    font-family: Arial, sans-serif;
    padding: 30px;
}

h1 {
    color: #ffd166;
}

h2 {
    color: #8be9fd;
}

li {
    margin-bottom: 8px;
}
```

Що роблять ці властивості:

- `background-color` змінює колір тла;
- `color` змінює колір тексту;
- `font-family` змінює шрифт;
- `padding` додає відступ від країв сторінки;
- `margin-bottom` додає відстань між елементами списку.

## Якщо потрібне перенесення рядка

Щоб примусово почати текст із нового рядка, використайте тег `<br>`. Наприклад:

```html
Перша зоря — золота.<br>
Друга зоря — блакитна.
```

Не ставте `<br>` після кожного речення без потреби. Для окремих абзаців краще використовувати тег `<p>`.

## Підказка для створення тексту

Якщо вам складно придумати назви або опис, можна попросити ChatGPT:

> Придумай назву фантастичної галактики, назви п'яти її планет і по три короткі особливості для трьох планет. Пиши просто й українською мовою.

Отриманий текст перенесіть у свою HTML-структуру самостійно.
