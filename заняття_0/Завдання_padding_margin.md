### 🔬 Padding чи Margin?

Є кнопка:

```html
<button>Натисни мене</button>
```

**1.** Додай:

```css
button {
    padding: 30px;
}
```

👉 Подивись, що змінилося.

**2.** Заміни `padding` на:

```css
margin: 30px;
```

👉 Що змінилося тепер?

**3.** Своїми словами поясни:

**Чим `padding` відрізняється від `margin`?**
