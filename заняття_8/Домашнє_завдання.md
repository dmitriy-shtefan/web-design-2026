# Домашнє завдання: Один текст - дві аудиторії

Оберіть тему, наприклад надійні паролі або сортування сміття. 
Складіть два запити до ШІ: для пояснення учням 3 класу та 
для повідомлення на шкільному сайті для батьків. В обох задайте обсяг і тон. 
Порівняйте відповіді: як змінилися слова, приклади та спосіб звертання?

Що здати: два запити, дві короткі відповіді ШІ та три конкретні відмінності між ними.
